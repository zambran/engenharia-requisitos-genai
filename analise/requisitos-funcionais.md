| ID | Requisito funcional |
| --- | --- |
| RF01 | O sistema deverá permitir visualizar os eventos disponíveis. |
| RF02 | O sistema deverá enviar um comprovante após a inscrição. |
| RF03 | O sistema deverá permitir o cancelamento da inscrição sem que seja necessário entrar em contato com a organização. |
| RF04 | O sistema deverá emitir um certificado de participação quando solicitado. | 
| RF05 | O sistema deverá permitir que participantes realizem inscrições em eventos/atividades. | 
| RF06 | O sistema deverá permitir que participantes consultem suas inscrições. | 
| RF07 | O sistema deverá controlar automaticamente a quantidade de vagas disponíveis. | 
| RF08 | O sistema deverá permitir a criação de lista de espera para eventos lotados. | 
| RF09 | O sistema deverá permitir aos organizadores acompanhar a quantidade de inscritos em tempo real. | 
| RF10 | O sistema deverá permitir aos organizadores consultar e gerenciar participantes. | 
| RF11 | O sistema deverá permitir cadastrar e gerenciar eventos. |
| RF12 | O sistema deverá controlar os horários das atividades. | 
| RF13 | O sistema deverá permitir inscrições em diferentes workshops, inclusive quando ocorrerem no mesmo dia. | 
| RF14 | O sistema deverá permitir configurar eventos gratuitos e eventos pagos. | 
| RF15 | O sistema deverá permitir confirmar pagamentos antes da liberação da inscrição quando essa condição for exigida pelo evento. | 
| RF16 | O sistema deverá permitir controlar solicitações e situações de reembolso. | 
| RF17 | O sistema deverá permitir ao palestrante consultar a lista de participantes de suas atividades, respeitando as permissões definidas. | 
| RF18 | O sistema deverá permitir que o participante consulte e obtenha seu certificado. |
